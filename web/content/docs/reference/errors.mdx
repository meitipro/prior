A refusal is a deterministic `UserError` whose sentence starts with `[EXPECTED]`. Validators agree on it byte for byte, so the transaction is **ACCEPTED** with an execution error. The site and the scripts treat that as a refusal, never as success: success is an accepted status **and** a leader execution that returned.

A model answer that cannot be read is `[LLM_ERROR]`. It always disagrees, so the round rotates to a committee that can answer; nothing is settled by it.
