## register

```python
register(seal: str) -> int
```

Store a seal with the chain time and the author's bond (at least 2 GEN). Returns the entry id.

Refuses with:

- a seal is a sha256 hash, 64 hex characters
- the bond is at least … GEN
- this seal is already registered

## reveal

```python
reveal(entry_id: int, text: str, salt: str) -> int
```

Publish the text, checked against its seal. The date never changes. Returns the entry id.

Refuses with:

- only the author of an entry may reveal it
- the salt is at most … characters and has no bar
- the text is empty
- the text is longer than … characters
- this entry is already revealed
- this text and salt do not match the seal

## challenge

```python
challenge(a_id: int, b_id: int) -> int
```

The author of the earlier entry A stakes 5 GEN against the later entry B. Both must be revealed and A sealed strictly before B. A pair can be challenged once. Returns the challenge id.

Refuses with:

- a challenge stakes exactly … GEN
- an entry cannot be challenged against itself
- both entries must be revealed first
- only the author of the earlier entry may file the challenge
- the earlier entry must have been sealed strictly before the later one
- this pair has already been challenged

## judge

```python
judge(challenge_id: int) -> str
```

Anyone asks the validators to compare the two texts. They never see dates, names or addresses; the contract applies the label and the seal dates. Never moves money out of the contract.

Refuses with:

- the earlier entry must have been sealed strictly before the later one
- this challenge was already read

## close_entry

```python
close_entry(entry_id: int) -> int
```

After 90 days with no open challenge and nothing upheld against it, anyone closes the entry: it is SEASONED and the bond is credited to its author. Returns the amount credited.

Refuses with:

- a challenge against this entry is still waiting to be read
- an entry marked as overlapping an earlier one does not season
- this entry has not been sealed for … days yet
- this entry is already seasoned

## withdraw

```python
withdraw() -> int
```

A top-level transfer of the caller's whole balance to the caller. The only call that pays.

Refuses with:

- nothing to withdraw
